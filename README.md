# Formula 1 Notification Telegram Bot

This is a project I created together with my friend to learn Python, work with APIs, and understand how real-world applications are structured. 
The bot helps Formula 1 fans never miss a session (practice, qualification, or race) by sending automatic reminders directly to Telegram.

# Tech Stack
- **Language:** Python
- **Libraries:** Aiogram, Asyncpg, Aiohttp, Python-dotenv
- **Testing:** Pytest

# Bot in Telegram

You can find the bot on Telegram: [@notifyf1_bot](https://t.me)

# How to Run the Bot

1. Clone the repository:
   ```bash
   git clone https://github.com
   cd f1-notify-bot
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Start the bot:
   ```bash
   python main.py
   ```
